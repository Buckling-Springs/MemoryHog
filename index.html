⚠️ What this page does This tool intentionally grows browser memory to help you test and debug memory-related issues. Use it to:
  • Array allocation – fills JavaScript heap with typed-array chunks so you can observe heap growth in DevTools (Memory tab / Task Manager).
  • Detached DOM nodes – creates DOM elements that are retained in JS but never attached to the document, simulating a classic memory-leak pattern.
  • Clear – releases all references so the garbage collector can reclaim memory.
Open your browser's DevTools → Memory tab (or Performance monitor) to observe the effects.
Do not use this on a machine where you need stable memory.

⚠️ Allocating large amounts of memory may slow down or crash your browser tab. Start small.
